Programación Web del lado del cliente
Reto 5 Crear un lector de noticias utilizando AJAX y JSON en JavaScript

INSTRUCCIONES
Crea una aplicación que pueda cargar y mostrar noticias en tiempo real empleando 
tecnologías como AJAX para obtener los datos en formato JSON y JavaScript para 
manipular y presentar la información a la persona usuaria.

PORTADA
En un documento de texto (como Word o Google Docs), presenta los siguientes datos en la 
primera página: 
• Nombre de la universidad 
• Nombre de la alumna o del alumno 
• Número de matrícula 
• Nombre del Módulo 
• Nombre del Reto 
• Nombre del Asesor o Asesora  
• Fecha de entrega

DESARROLLO DEL LECTOR DE NOTICIAS
Utiliza un editor de desarrollo web de tu preferencia (como VS Code o Eclipse) y realiza las siguientes acciones:
• Establece una estructura HTML básica para presentar las noticias, considera un encabezado, un cuerpo principal y un área específica donde se mostrarán las noticias.
• Implementa una función en JavaScript que use el método Fetch para hacer una petición a una de las siguientes APIs de noticias: NewsAPI, GNews u otro proveedor de API gratuito de tu elección. 
• Obtén los datos en formato JSON. 
• Procesa la respuesta obtenida para extraer las noticias y presentarlas en el área designada de tu página web. 
• Asegúrate de manejar posibles errores, como cuando la API no esté disponible o cuando no haya noticias disponibles. 
• Proporciona una opción para que la persona usuaria pueda refrescar las noticias sin necesidad de recargar toda la página. 

ESTILIZACION Y DINAMISMO
No olvides que la presentación es crucial para la experiencia de la persona usuaria: 
• Aplica estilos básicos para hacer que la lectura de las noticias sea agradable y clara. 
• Implementa interacciones básicas, como poder hacer clic en el título de una noticia para leerla completa. 

RESUMEN Y CAPTURAS
En tu documento crea un resumen que explique la lógica detrás de tu lector de noticias, cómo implementaste Fetch y cómo procesaste el JSON recibido de las APIs mencionadas.
• Añade capturas de pantalla de tu aplicación en funcionamiento, mostrando las noticias cargadas. 
• No olvides incluir también capturas de pantalla del código JavaScript que has desarrollado, especialmente las partes donde implementas Fetch y manejas los datos en formato JSON.

FUENTES Y REFERENCIAS
Incluye cualquier referencia o fuente que hayas consultado durante el desarrollo del reto 
en formato APA en tu documento de texto.

Este Reto busca que domines tecnologías clave en el desarrollo web moderno, como son Fetch, JSON y JavaScript, y la interacción con APIs de terceros para crear aplicaciones web 
dinámicas. La capacidad de integrar y presentar datos en tiempo real de diferentes fuentes es una habilidad esencial en el mundo digital actual.
¡Buena suerte y esperamos ver tus creativas implementaciones!
